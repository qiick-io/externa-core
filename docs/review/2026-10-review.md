# Externa-Core Analysis — October 2026

**Version reviewed:** 1.1.0  
**Analysis date:** October 18, 2026  
**Scope:** Security, code quality, AI extensions, Directus comparison, roadmap

---

## Executive summary

Externa-core is a mature Laravel-native headless CMS (v1.1.0) with solid architectural foundations. The review identifies 23 priority recommendations across 5 areas: API/upload security, AI modernization (automatic image classification), gaps compared to Directus, codebase quality, and alignment with the existing GitHub milestones.

**Main risks:**
- ⚠️ **HIGH**: No granular rate limiting on the public API/GraphQL (milestone 1.3.0 already plans it)
- ⚠️ **MEDIUM**: Upload MIME validation based only on the extension (issue #118 open)
- ⚠️ **MEDIUM**: Missing AuthZ regression suite (milestone 1.3.0)

**Key opportunities:**
- ✅ AI file classification with laravel/ai 1.1+ (OpenAI/Anthropic vision)
- ✅ Native MCP server (milestone 1.4.0) to compete with Directus
- ✅ Field-level ACL and workspace isolation (1.4.0)

**Test coverage:** 129 tests present, but regression tests for AuthZ and API performance are missing.

#### ⚠️ CRITICAL VULNERABILITIES/GAPS

**1.1.1 HIGH PRIORITY: Inadequate public API rate limiting**

**Problem:**
```20:27:routes/api.php
Route::prefix('v1')
    ->middleware(['throttle:api', EnforcePublicApiOrigin::class, ResolveApiAccess::class])
    ->group(function (): void {
        Route::get('collections', [CollectionController::class, 'index']);
        Route::get('collections/{slug}', [CollectionController::class, 'show']);
        Route::get('collections/{slug}/items', [CollectionItemController::class, 'index']);
        Route::post('collections/{slug}/items', [CollectionItemController::class, 'store']);
```

Laravel's default `api` throttle is global (60 req/min per IP). There is no:
- Budget for nested GraphQL queries (include-depth, payload size)
- Specific rate limit for mutations vs queries
- Per-collection abuse cap
- Cost-based limiting (1 query = 1 token, 1 deep include = 5 tokens, etc.)

**Impact:** DoS via abusive GraphQL, untracked API scraping.

**Recommended fix:** Implement `ApiRequestCostMiddleware` with a token bucket:

```php
// app/Http/Middleware/ApiRequestCostMiddleware.php
class ApiRequestCostMiddleware
{
    public function handle(Request $request, Closure $next): Response
    {
        $cost = $this->calculateCost($request);
        $key = 'api-cost:' . ($request->user() ?? $request->ip());
        
        if (RateLimiter::tooManyAttempts($key, config('api.cost_limit', 1000))) {
            abort(429, 'API cost budget exceeded');
        }
        
        RateLimiter::hit($key, 60, $cost);
        return $next($request);
    }
    
    private function calculateCost(Request $request): int
    {
        // 1 per query base, +2 per include, +5 per mutation, +10 per nested relation
        $cost = 1;
        if ($request->isMethod('POST') || $request->isMethod('DELETE')) {
            $cost += 5;
        }
        if ($includes = $request->input('include')) {
            $cost += count(explode(',', $includes)) * 2;
        }
        return $cost;
    }
}
```

**File:** `app/Http/Middleware/ApiRequestCostMiddleware.php` (new)  
**Milestone:** 1.3.0 — issue #113 "Public API & GraphQL: rate limits, include-depth caps, payload budgets"

#### ⚠️ CRITICAL VULNERABILITIES

**1.3.1 HIGH PRIORITY: Insufficient MIME type validation**

**Problem:**

```68:70:app/Services/FileService.php
$fileName = PlainTextSanitizer::sanitize($name ?? $uploadedFile->getClientOriginalName()) ?? '';
ForbiddenUploadExtension::assertAllowed($fileName, $name !== null ? 'name' : 'file');
$mimeType = $uploadedFile->getMimeType();
```

Validation based only on the **filename extension** (client-controlled). `getMimeType()` uses `finfo` but there is no MIME whitelist per upload type.

**Attack scenario:**
1. Attacker renames `malware.exe` → `invoice.pdf`
2. Extension check passes (`.pdf` ok)
3. File served with `Content-Type: application/pdf` but contains a PE executable
4. If an admin downloads and runs it → compromise

**Recommended fix:**

```php
// app/Support/Uploads/MimeTypeValidator.php
final class MimeTypeValidator
{
    private const ALLOWED_MIME_TYPES = [
        'image' => ['image/jpeg', 'image/png', 'image/gif', 'image/webp'],
        'document' => ['application/pdf', 'application/msword', 'application/vnd.openxmlformats-officedocument.wordprocessingml.document'],
        'video' => ['video/mp4', 'video/webm'],
        // ...
    ];
    
    public static function assertAllowed(UploadedFile $file, string $field = 'file'): void
    {
        $detectedMime = $file->getMimeType();
        $extension = strtolower($file->getClientOriginalExtension());
        
        // Extension already checked by ForbiddenUploadExtension
        
        // Verify MIME matches the expected extension
        $expectedMimes = self::getAllowedMimesForExtension($extension);
        if (!in_array($detectedMime, $expectedMimes, true)) {
            throw ValidationException::withMessages([
                $field => ['File type mismatch. Extension suggests different type.'],
            ]);
        }
        
        // Magic bytes check for critical formats
        if (in_array($extension, ['pdf', 'jpg', 'png', 'gif'])) {
            if (!self::verifyMagicBytes($file, $extension)) {
                throw ValidationException::withMessages([
                    $field => ['File appears corrupted or not a valid ' . $extension],
                ]);
            }
        }
    }
    
    private static function verifyMagicBytes(UploadedFile $file, string $extension): bool
    {
        $handle = fopen($file->getRealPath(), 'rb');
        $header = fread($handle, 16);
        fclose($handle);
        
        return match($extension) {
            'pdf' => str_starts_with($header, '%PDF-'),
            'jpg', 'jpeg' => str_starts_with($header, "\xFF\xD8\xFF"),
            'png' => str_starts_with($header, "\x89PNG\r\n\x1A\n"),
            'gif' => str_starts_with($header, 'GIF87a') || str_starts_with($header, 'GIF89a'),
            default => true,
        };
    }
}
```

**Integration:** `FileService::uploadFile()` line 69  
**Milestone:** 1.3.0 — issue #118 "Security hardening pass: upload MIME allowlists + Public API SSRF/open-redirect review"

**2.1.1 MEDIUM PRIORITY: Ponytail comments indicate scaling limits**

**Problem:**

```70:70:app/Services/Api/FilePermissionGuard.php

```


"Ponytail" = declared tech debt. 2 cases:

1. **FilePermissionGuard:** Loads all files into memory to compute effective access (parent inheritance). On 100k+ files → OOM.
2. **FileService upload:** Loads the whole file into RAM for the SHA256 hash. Files >1GB → problem.

**Recommended fix:**

**File permissions:** Denormalize `effective_access` into an indexed column:

```php
// Migration
Schema::table('files', function (Blueprint $table) {
    $table->string('effective_access', 20)->nullable()->index();
});

// Model observer
class FileObserver
{
    public function saving(File $file): void
    {
        if ($file->isDirty('access') || $file->isDirty('parent_id')) {
            $file->effective_access = $this->resolveEffectiveAccess($file);
        }
    }
}
```

**File upload hash:** Use a streaming hash:

```php
$context = hash_init('sha256');
$handle = fopen($uploadedFile->getRealPath(), 'rb');
while ($chunk = fread($handle, 8192)) {
    hash_update($context, $chunk);
}
fclose($handle);
$fileHash = hash_final($context);
```

**Milestone:** 1.3.0 issue #117 "Collections admin/API list query audit (N+1 + column select)"

#### 3.3.2 Job: ClassifyFileJob

```php
// app/Jobs/ClassifyFileJob.php
namespace App\Jobs;

use App\Models\File;
use App\Services\Ai\FileClassificationService;
use Illuminate\Bus\Queueable;
use Illuminate\Contracts\Queue\ShouldQueue;
use Illuminate\Queue\InteractsWithQueue;
use Illuminate\Queue\SerializesModels;

class ClassifyFileJob implements ShouldQueue
{
    use InteractsWithQueue, Queueable, SerializesModels;

    public function __construct(
        public File $file,
        public bool $autoOrganize = true,
    ) {}

    public function handle(FileClassificationService $classifier): void
    {
        // Skip if already processed or unsupported type
        if ($this->file->ai_processed || !$this->file->isClassifiable()) {
            return;
        }

        $metadata = $classifier->classify($this->file);
        
        $this->file->update([
            'ai_metadata' => $metadata,
            'ai_processed' => true,
            'ai_processed_at' => now(),
        ]);

        if ($this->autoOrganize) {
            $classifier->organizeFile($this->file, $metadata);
        }

        // Automatic tags
        $classifier->applySuggestedTags($this->file, $metadata['tags'] ?? []);
    }
}
```

#### 3.3.3 Service: FileClassificationService

```php
// app/Services/Ai/FileClassificationService.php
namespace App\Services\Ai;

use App\Models\File;
use App\Services\FileService;
use Illuminate\Support\Facades\Storage;
use Laravel\Ai\Facades\AI;
use Spatie\Tags\Tag;

class FileClassificationService
{
    public function __construct(
        private FileService $fileService,
    ) {}

    /**
     * @return array{category: string, tags: array<string>, colors: array<string>, contains_faces: bool, text_content: string|null, confidence: float, model_version: string}
     */
    public function classify(File $file): array
    {
        if (!$file->isClassifiable()) {
            throw new \InvalidArgumentException('File type not classifiable');
        }

        $path = Storage::disk($file->disk)->path($file->storage_path);
        
        $result = AI::vision()
            ->model(config('ai.vision_model', 'gpt-4-vision'))
            ->analyze($path)
            ->withSchema([
                'category' => 'string',
                'tags' => 'array',
                'dominant_colors' => 'array',
                'contains_faces' => 'boolean',
                'text_content' => 'string|null',
                'confidence' => 'number',
            ])
            ->prompt($this->buildPrompt($file))
            ->get();

        return [
            'category' => $result['category'],
            'tags' => $result['tags'],
            'colors' => $result['dominant_colors'],
            'contains_faces' => $result['contains_faces'],
            'text_content' => $result['text_content'],
            'confidence' => $result['confidence'],
            'model_version' => config('ai.vision_model', 'gpt-4-vision'),
        ];
    }

    private function buildPrompt(File $file): string
    {
        $isPdf = $file->mime_type === 'application/pdf';
        
        return $isPdf
            ? 'Analyze this PDF document and extract: category (invoice/contract/presentation/report/other), relevant business tags, whether it contains signatures or faces, and extract any text content (max 500 chars).'
            : 'Analyze this image and extract: category (product/nature/document/person/screenshot/artwork/other), descriptive tags (min 3, max 10), dominant colors (hex codes), whether it contains human faces, and any visible text (OCR).';
    }

    /**
     * Organize the file into a folder based on its category
     */
    public function organizeFile(File $file, array $metadata): void
    {
        $category = $metadata['category'];
        $targetFolderName = match($category) {
            'product' => 'Products',
            'document', 'invoice', 'contract' => 'Documents',
            'person' => 'People',
            'nature', 'artwork' => 'Media',
            default => 'Unsorted',
        };

        // Create the folder if it does not exist
        $targetFolder = File::query()
            ->where('name', $targetFolderName)
            ->where('type', 'folder')
            ->whereNull('parent_id')
            ->first();

        if (!$targetFolder) {
            $targetFolder = $this->fileService->createFolder($targetFolderName);
        }

        // Move only if it is not already in the target folder
        if ($file->parent_id !== $targetFolder->id) {
            $this->fileService->move($file, $targetFolder->id);
        }
    }

    /**
     * Apply tags suggested by the AI
     */
    public function applySuggestedTags(File $file, array $tags): void
    {
        foreach ($tags as $tagName) {
            // Spatie tags package
            $file->attachTag($tagName);
        }
    }
}
```
